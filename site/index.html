PULSAR

Steady light. Atomic core.

An immutable Fedora spin for gaming and development. Built in the cloud, signed end to end, updates itself quietly.

sudo bootc switch ghcr.io/arclight-digital/pulsar:latest

NVIDIA laptop? Use pulsar-nvidia — the kernel module arrives pre-built and pre-signed for Secure Boot.

Play

Gamescope, MangoHud, and the scx_lavd scheduler picked for frame pacing. Flathub is preconfigured for Steam and everything else.

Build

Distrobox for any userland, libvirt/KVM for real machines, GitHub CLI and JetBrains Mono out of the box.

Trust

Every image is built and signed on public CI with provenance attestations. The NVIDIA kernel module is signed against the MOK cert the image itself carries.

Updates, the boring way

Images build nightly. Your machine notices, stages the update, and GNOME Software tells you a reboot away — exactly how stock Silverblue behaves. Nothing builds, compiles, or signs on your hardware. Ever.
