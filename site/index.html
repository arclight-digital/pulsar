PULSAR

Fedora with a pulse.

An immutable Silverblue spin tuned for gaming and development — built, signed, and attested in the cloud. Your machine never compiles a thing.

standard sudo bootc switch ghcr.io/arclight-digital/pulsar:latest
nvidia sudo bootc switch ghcr.io/arclight-digital/pulsar-nvidia:latest

On Fedora Silverblue or Kinoite 44+: run one, reboot, done. The nvidia cut ships its kernel module pre-built and pre-signed for Secure Boot.

What's inside

The scheduler is scx_lavd, picked because stock EEVDF places threads badly on a big hybrid die. Gamescope, gamemode, and MangoHud are system-level; split-lock mitigation is off and the map count is raised because real games want both. Flathub arrives unfiltered and image-native.

For work: distrobox for any userland, libvirt/KVM for real machines, GitHub CLI in the base. Anything you merely run is a Flatpak — the image is the OS, not an app store.

And the part most spins won't do: the NVIDIA open kernel module is compiled against the image's exact kernel and signed in CI, so Secure Boot stays on.

Every image has a paper trail

  1. commitpush to main
  2. buildboth images, nightly
  3. signkmod keyed to the shipped MOK cert
  4. attestSLSA provenance on ghcr
  5. bootbootc switches to the signed image

Don't take the page's word for it:

verify gh attestation verify oci://ghcr.io/arclight-digital/pulsar-nvidia:latest --owner arclight-digital

One person's laptop OS, over-engineered on purpose, MIT-licensed. Running someone else's signed images is a trust decision — fork it and use your own key if that's not a relationship you want.
